# Documentación del Proyecto SCLINIC

Bienvenido a la base de conocimiento centralizada de SCLINIC. Estos documentos se mantienen actualizados con el desarrollo del sistema para servir como fuente única de verdad sobre las reglas y el funcionamiento de la plataforma.

## 📂 Contenido
- [**Reglas de Negocio**](business_rules.md): Lógica central, Soft Locks, alertas médicas y liquidación de seguros.
- [**Arquitectura del Sistema**](architecture_overview.md): Estructura técnica de apps Django, multi-tenancy e integración de datos.
- [**Estructura de Carpetas**](folder_structure.md): Resumen de la organización del código por dominios.
- [**Guía de Funcionalidades**](features_guide.md): Catálogo de capacidades actuales (HCE, Agenda, B2B, Salud Ocupacional).
- [**E-R Diagram**](entity_relationship_diagram.md): Mapa visual de la base de datos y relaciones.
- [**Requerimientos**](requirements/README.md): Documentación detallada de requerimientos funcionales.

## 📌 Principio Clave
SCLINIC prioriza el **aislamiento total de datos**, la **seguridad de la información médica** (HIPAA-compliant principles) y la **escalabilidad B2B** para clínicas de alta demanda.
